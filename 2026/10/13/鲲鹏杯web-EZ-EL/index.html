本题考点:Freemarker 模板注入 SSTI（服务器端模板注入），文件上传点，但不是上传 webshell，而是利用文件名可控触发模板引擎执行，最后盲注读取服务器上的 /flag 文件。
Flag：NSSCTF{a2bc0cec-0bb0-46f1-965a-b9b01f60c8f8}

打开靶场，页面返回 HTTP Status 404-Not Found，得不到任何内容，猜测需要通过其他的路口访问

尝试/api,发现页面会返回一个工作台,尝试登入了一会，发现没什么结果，于是继续寻找接口

访问接口文档地址：/api/v3/api-docs，页面返回一大段 JSON，这是 OpenAPI（Swagger）接口文档，会把后端所有暴露的 API 全部列出来
页面源码里面有这样一句话:
上传模板文件，服务器以文件名为模板内容进行渲染
这说明它会渲染我上传的文件名，所以我可以上传一个特殊的文件名,先实验一下#{7*7}
(#{7*7} 是 Freemarker 插值语法，引擎会把里面表达式运算，把结果替换回输出。)

使用bp构造上传文件的数据包，将fliename后面的值设置为#{7*7},发现它返回了49，这说明我的思路是对的
