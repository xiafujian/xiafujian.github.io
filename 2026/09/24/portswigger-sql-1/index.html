补充：数据库其实有四种

做题时发现自己的一个知识点盲区 —— 常见数据库有四种，注入语法并不完全一样。

名称 常见场景
Oracle 甲骨文的大型商业数据库，企业和老系统用得多
Microsoft SQL Server Windows 服务器常用
PostgreSQL 开源，很多现代网站和靶场在用
MySQL PHP + MySQL，Web 安全练习最常碰到

四者的注释符、字符串拼接、报错函数、系统表名都有差异，这块还需要单独补。
