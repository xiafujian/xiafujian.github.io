Lab: SQL注入

  • 使用portswigger靶场：

之前使用的sql-lab靶场全部都是MYSQL的数据库,但是不同数据库注入语法有所不同，这篇是oracle数据库的sql注入

打开靶场，在页面中随便点一点后，发现点击商品分类后，地址栏出现?category=,这时候就可以判断这是get型的注入

尝试了一些基本的闭合方式，最后确认是'闭合
于是构造?category='
发现出现空白页面，以及回显了一些奇怪的字符

首先先确定列数
构造?categoty=' order by 1--
?categoty=' order by 2--
?categoty=' order by 3--
发现3的时候页面空白报错，可以确定此题是两列


还有一种方法是构造?categoty=' union select 'abc','abc' from dual--
发现页面返回两列，也可以确定

注：Oracle 必须写 FROM dual！这是 Oracle 和 MySQL 最大区别
Oracle 每一条 SELECT 必须带 FROM，不能直接 select null，要用伪表 dual

最后构造?category=' union select banner,null from v$version--
成功获得版本号，靶场也提示注入成功

最后有一点我没遇到的：
UNION 要求对应位置的数据类型兼容：数字列放字符串会报错，字符串列放文本才正常。
我最开始使用的就是字符串，这一题也恰好支持字符串
